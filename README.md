# File Organizer (Python Automation)

This project automatically organizes files in a given folder by moving them into subfolders based on their file extensions. It is especially useful for keeping your Downloads folder or other directories tidy.

---

## 🛠 Features

- Organizes files by type (images, documents, spreadsheets, music, videos).  
- Files that do not fit into predefined categories are moved to the `others/` folder.  
- Automatically creates target folders if they do not exist.  
- Can be executed via terminal with the `--path` argument to specify the target folder.  
- (Future extensions) simulation mode, logging, duplicate handling.
